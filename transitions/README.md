# transitions/

Shared GLSL transition assets — the single source of truth consumed by **both** the
native renderer (`src/native/lp-transition`) and the React UI's live previews
(`app/ui` `TransitionPicker`). Authoring an effect once works in both places.

## Layout
- `glsl/<id>.glsl` — one transition body per effect: a `vec4 transition(vec2 uv)`
  function using `getFromColor(uv)` / `getToColor(uv)` / `progress` / `ratio`, plus any
  `uniform`s (kept verbatim, defaults applied by the host from `manifest.json`).
- `manifest.json` — `[{ id, name, category, defaultOn, author, license, uniforms[] }]`.
  `uniforms[]` = `{ name, type, default:[numbers] }`; the host sets each via `glUniform`
  at load (e.g. a `float` → `[0.5]`, an `ivec2(20)` → `[20,20]`, a `vec4` → `[r,g,b,a]`).
- `wrap.vert` / `wrap.frag.template` — the standard wrapper. The host substitutes the
  effect body into `//<<BODY>>` in the fragment template. GLES 3.00 / WebGL2
  (`#version 300 es`), samplers named `fromTex`/`toTex` (bodies define their own local
  `from`/`to`), `#define texture2D texture`, and the
  `GL_EXT_shader_non_constant_global_initializers` extension (a few effects use
  non-constant globals — real GL/WebGL allow this).
- `preview/a.jpg`, `preview/b.jpg` — two contrasting sample frames for the UI tiles.

## Source & license
Effects are bundled from [gl-transitions](https://github.com/gl-transitions/gl-transitions)
(MIT — see `LICENSE.gl-transitions`); per-effect `author`/`license` are preserved in
`manifest.json`. Regenerated by `scripts/generate_transitions.py` (transforms the upstream
sources: strips header comments → manifest, parses uniform defaults, validates each wrapped
shader with `glslangValidator`, drops any needing extra sampler inputs or that fail to
compile). 122 of 125 upstream effects are included.
